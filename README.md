# CogLab

CogLab is a web-based cognitive experimentation project.

## Current Version

v0.1 — Simple Reaction Time Task

The current experiment measures how quickly a participant
responds to a visual stimulus.

A green circle appears after a waiting period and the participant
responds by pressing the Space key.

The experiment records reaction times over multiple trials and
calculates the mean reaction time.

## Current Features

- Visual stimulus presentation
- Keyboard response collection
- Reaction time measurement
- Multiple trials
- Mean reaction time calculation

## Long-Term Goal

CogLab will evolve into a modular platform for conducting and
analyzing behavioral cognitive experiments involving attention,
working memory, executive control and human decision-making.

## Planned Experiments

- Stroop Task
