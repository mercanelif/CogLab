# CogLab Project Context

## Project

CogLab is an open-source web platform for conducting
and analyzing cognitive psychology experiments.

The project is being developed as a Computer Science
student portfolio project.

The developer is currently a beginner programmer.

Therefore:

- Prefer simple implementations.
- Explain important programming concepts.
- Do not introduce unnecessary libraries.
- Do not generate large amounts of code without explanation.
- Break complex tasks into small steps.
- Explain architectural decisions.
- Prefer readable code over clever code.

## Long-term Goal

The platform will eventually support:

- Stroop Test
- N-Back
- Go/No-Go
- Visual Search
- Reaction Time experiments

The system will eventually contain:

Frontend
    JavaScript / later React

Backend
    Python FastAPI

Database
    PostgreSQL

Analysis
    Python
    Pandas
    SciPy
    statsmodels

Deployment
    Docker

## Current Development Strategy

The project must be developed incrementally.

Phase 1:
Simple reaction-time experiment.

Phase 2:
Stroop experiment.

Phase 3:
Export results as JSON/CSV.

Phase 4:
Python statistical analysis.

Phase 5:
FastAPI backend.

Phase 6:
PostgreSQL database.

Phase 7:
N-Back experiment.

Phase 8:
Dashboard.

Phase 9:
Docker.

Phase 10:
Adaptive experiment using machine learning.

## Development Principles

Never implement several phases simultaneously.

Before writing code:

1. Explain what we are going to build.
2. Explain the programming concepts involved.
3. Explain which files will change.
4. Suggest the smallest implementation.

After writing code:

1. Explain the code.
2. Explain how to run it.
3. Explain how to test it.
4. Explain common errors.
